# 💰 Website Mercado Financeiro

Website otimizado sobre mercado financeiro desenvolvido com HTML5, CSS3 e p5.js.

## 📋 Características

- **Layout Responsivo**: Funciona perfeitamente em desktop, tablet e mobile
- **Gráficos Interativos**: Visualizações de dados com p5.js
- **Dashboard Financeiro**: Acompanhamento de Ibovespa, Dólar, Ouro e Criptomoedas
- **Notícias Atualizadas**: Seção dedicada às últimas notícias do mercado
- **Design Moderno**: Interface dark mode com cores otimizadas
- **Código Otimizado**: HTML, CSS e JavaScript sem dependências externas pesadas

## 🎨 Seções

1. **Header Sticky**: Navegação fixa no topo com logo e menu
2. **Hero Section**: Apresentação do website com call-to-action
3. **Análise Técnica**: Gráfico interativo com p5.js mostrando tendências de mercado
4. **Cards de Informação**: Dados em tempo real de 4 principais índices
5. **Notícias**: Últimas notícias sobre mercado financeiro
6. **Footer**: Informações de rodapé e créditos

## 📂 Estrutura de Arquivos

```
.

├── styles.css      # Estilos CSS otimizados
├── sketch.js       # Gráfico p5.js
```

## 🚀 Como Usar

### Localmente
1. Clone o repositório
2. Abra o arquivo `index.html` em um navegador web
3. Pronto! O website está funcionando

### Deploy
1. Faça upload dos arquivos para seu servidor web
2. Acesse através da URL configurada

## 📊 Dados do Mercado

Os dados são simulados e atualizados a cada 5 segundos:

- **Ibovespa**: Índice principal da bolsa brasileira
- **Dólar**: Taxa de câmbio USD/BRL
- **Ouro**: Cotação do ouro em USD
- **Bitcoin**: Criptomoeda principal
